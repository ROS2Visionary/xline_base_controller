# 航向校准方案设计文档

## 背景与问题

### 系统构成

- **定位**：全站仪跟踪反射板，XY 精度 3mm
- **姿态**：MINS500 IMU，航向保持精度 0.1°/min，动态精度 0.1°
- **地面**：新浇筑水泥，存在不平整

### 航向估计方式（现有）

```
robot_yaw = (imu_current_yaw - imu_initial_yaw) + robot_initial_yaw
```

`robot_initial_yaw` 通过"让机器人走直线、拟合轨迹方向"建立。
`imu_initial_yaw` 在校准完成时同步记录。

### 精度需求

目标 p90 < 5mm，v = 0.25 m/s。
允许的最大持续航向误差：

```
θ_max = 5mm / (0.25 m/s × 2s) ≈ 0.57°
```

---

## 现有方案的问题分析

### 误差来源（按量级排序）

#### 1. 主要矛盾：校准行程过短导致拟合精度不足

现有校准：`v=0.05 m/s × 3s = 0.15m`，约 60 个位置点。

线性回归航向精度：

```
σ_θ = σ_pos × √(12/N) / L = 3mm × √(12/60) / 150mm ≈ 0.51°
```

0.51° 已逼近 0.57° 极限，约 32% 概率超限，且作为系统性偏置全程保留。

#### 2. 机械偏差（走弧线）

校准时只给线速度，机械不对称导致机器人走弧线（曲率半径 R）。
最小二乘拟合返回弦方向，与真实朝向偏差：

```
系统性偏置 = s / (2R)

R=50m，s=0.15m：偏置 = 0.086° （可接受）
R=20m，s=0.5m： 偏置 = 0.72° （不可接受）
```

**延长行程并不能消除机械偏差，反而会放大**——与降低噪声的需求相互矛盾。

#### 3. MINS500 运行漂移（非主要问题）

```
60s 漂移 = 0.1°
对应侧向漂移（2s段）= 0.25 × sin(0.1°) × 2 ≈ 0.9mm
```

配合 LQR 积分项，完全可吸收，**不是瓶颈**。

## 新方案：LQR 主动走直校准

### 核心思路

校准 = **用现有 LQR 跑一段 0.5m 的临时直线路径**

校准和路径跟随本质是同一件事，区别只是：
- 路径跟随：跟随预定义任务路径
- 校准：跟随一条临时生成的 0.5m 直线，用走出的轨迹标定航向

### 执行流程

```
① 以当前位置为起点，沿某方向（优先与下一段任务路径方向一致）
   生成一条 0.5m 的临时两点路径

② 调用现有 LQR 执行跟随（不修改任何控制参数）

③ 全程记录全站仪位置点，监控滤波后的 e_y（Hampel + SG 滤波）

④ 质量判定：
   - 均值 |e_y| < 2mm 且 p90(|e_y|) < 3mm → 成功
   - 否则 → 放弃，重新选方向，重试
   （重试次数上限建议 5 次，超限则上报错误）

⑤ 成功后对全程位置点做最小二乘直线拟合

⑥ 更新锚点：
   robot_initial_yaw_ = 拟合方向角
   imu_initial_yaw_   = 此刻 IMU 读数
```

### 为什么能打破循环依赖

LQR 的 e_y 完全来自全站仪绝对位置和路径几何，**与当前航向估计无关**：

```
校准线 = 当前位置 → 目标点（纯世界坐标）
e_y    = 机器人到这条线的垂直距离（纯位置计算）
```

即使航向估计很粗糙，e_y 控制仍能把机器人拉到直线上。
质量门控（均值 < 2mm）是对"机器人确实走直了"的独立验证，与航向估计准不准无关。

### 航向粗糙时的收敛性

LQR 输出：`ω = -K1 × e_y - K2 × e_theta`

- **K1 × e_y**：始终正确，主导拉直
- **K2 × e_theta**：航向粗糙时提供略偏的阻尼

最坏情况（航向误差 5°，v=0.1 m/s）：
- 收敛距离 < 0.15m
- 剩余 0.35m 为稳定直线段，足够可靠拟合

## 精度分析

### 新方案航向精度

LQR 保证 e_y < 3mm（已验证），位置点噪声仅剩全站仪测量噪声。

```
校准速度 0.1 m/s × 5s = 0.5m，20Hz → N=100 点

σ_θ = 3mm × √(12/100) / 500mm ≈ 0.12°
```

对应最大侧向漂移（2s 路径段）：
```
0.25 × sin(0.12°) × 2 ≈ 1.0mm  （远低于 5mm 目标）
```

此精度已达当前硬件的理论下限：`σ_θ = σ_pos × √(12/N) / L`。

### 与现有方案对比

| 对比项 | 现有方案 | 新方案 |
|--------|---------|--------|
| 机械偏差 | 开环，行程越长越差 | LQR 闭环消除 |
| 地面抖动 | 靠平均减弱 | LQR 实时修正 + 重试过滤 |
| 循环依赖 | 无 | 无（e_y 不依赖航向）|
| 航向精度 σ_θ | ~0.51° | ~0.12°（提升 4 倍）|
| 新增代码量 | — | 极少（控制器完全复用）|

## 实现变动清单

### `motion_control_center.cpp`

`executeLocalizationCalibration()` 函数：

```
旧逻辑：发布固定线速度 0.05 m/s，持续 3s
新逻辑：
  1. 生成临时路径：[current_pos, current_pos + 0.5m（优先沿任务路径方向）]
  2. 调用现有 LQR 路径跟随执行器
  3. 实时监控滤波后的 e_y
  4. 质量判定：均值 < 2mm 且 p90 < 3mm
  5. 失败则重试（换方向），上限 5 次
```

### `localization_node.cpp`

`finishCalibration()` / `calibratePoseCallback()`：

```
旧逻辑：固定收集 3s 数据后拟合
新逻辑：
  接收来自 motion_control_center 的位置点序列（已通过质量门控）
  直接做最小二乘拟合，无需内部计时
```

**所有其他模块不变**：LQR 控制器、最小二乘拟合、IMU 融合逻辑、60s 触发周期。

## 边界情况处理

| 情况 | 处理方式 |
|------|---------|
| 地面大凸起（瞬间 e_y > 3mm）| 触发重试，换方向 |
| 首次启动航向完全未知 | 第一次可能重试 1-2 次，每次走完后航向逐步收敛 |
| 重试 5 次仍失败 | 上报错误，等待人工干预或选择更平整区域 |
| 质量门控过于严格 | 阈值可配置，建议初始值：均值 2mm，p90 3mm |

---

## 结论

> 方案无本质缺陷，在当前硬件约束（单全站仪 3mm + MINS500）下是最优解。
> 将专用校准流程归约为"带质量验证的短路径跟随"，复用所有已验证组件，
> 航向初始精度从 ~0.51° 提升至 ~0.12°，提升约 4 倍。
> 如需进一步提升，需硬件变动（双反射板或磁力计）。
