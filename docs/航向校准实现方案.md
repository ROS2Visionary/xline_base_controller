# 航向校准执行流程

## 一、触发入口

```
外部调用 /motion_control/calibration_service (std_srvs/Trigger)
        |
        v
handleCalibrationService()
  - 检查 is_executing_ / is_calibrating_（state_mutex_ 保护）
  - 若任一为 true → 拒绝，返回 success=false
  - 设置 is_calibrating_ = true
  - 立即返回 success=true（"校准已启动"）
  - 在 detached 线程中执行 executeLocalizationCalibration()
```

---

## 二、校准策略选择

```
executeLocalizationCalibration(speed=0.10, max_retries=5)
        |
        v
检查 initialized_（本地标志位，由 initPose 成功后置 true）
        |
   +----+----+
   |         |
false      true
   |         |
   v         v
Bootstrap   LQR 精确校准
校准方案    方案
```

---

## 三、Bootstrap 校准方案（首次开机）

```
executeBootstrapCalibration(speed)
        |
        v
调用 /localization/calibrate_pose（开始收集反射板位置数据）
        |
        v
以固定线速度 speed 向前行走 0.4m
  - 每 20ms 发布一次 cmd_vel（v=speed, ω=0）
  - 循环检查 shutdown_ / 已行走距离
        |
        v
停车（发布零速度）
        |
        v
调用 /localization/apply_calibration（停止收集 + 拟合 + 更新锚点）
  - localization_node 内部：
      跳过前 1/3 收敛段样本
      最小二乘直线拟合（fitLine）
      initPose 计算初始航向
        |
        v
返回校准结果（success / error_msg）
```

---

## 四、LQR 精确校准方案（已有航向锚点）

```
executeLQRCalibration(speed, max_retries)
        |
        v
+---------------------------------------------------+
| retry 循环（最多 max_retries 次）                  |
|                                                   |
|  检查 shutdown_ -> 立即退出                        |
|        |                                          |
|        v                                          |
|  等待有效位姿（has_latest_pose_）                  |
|  超时 5s -> 本次重试失败                           |
|        |                                          |
|        v                                          |
|  以当前位置 + 朝向生成 0.4m 临时路径               |
|  调用 /localization/calibrate_pose                |
|  （开始收集反射板位置数据）                        |
|        |                                          |
|        v                                          |
|  初始化 LineFollowController                      |
|  设置速度上限 speed                                |
|        |                                          |
|        v                                          |
|  LQR 主循环                                       |
|  while(rclcpp::ok() && !shutdown_)               |
|    checkPauseState()                              |
|    getLatestPose()                                |
|    line_follow_controller_->                      |
|      computeVelocityCommands()                    |
|    发布 cmd_vel                                   |
|    检查路径是否完成（goal_reached）                |
|        |                                          |
|        v                                          |
|  停车（发布零速度）                                |
|        |                                          |
|  检查 shutdown_ -> 跳过评估直接退出                |
|        |                                          |
|        v                                          |
|  质量门控评估 e_y 序列：                           |
|    mean(|e_y|) < 2mm                             |
|    p90(|e_y|) < 3mm                              |
|        |                                          |
|   +----+----+                                     |
|   |         |                                     |
| 通过       不通过                                 |
|   |         |                                     |
|   v         v                                     |
| apply     abort_calibration                       |
| 成功退出   sleep(2s,分段检查 shutdown_) -> 下一次  |
+---------------------------------------------------+
        |
   成功 / 全部重试失败
        |
        v
调用 line_follow_controller_->cancel()（重置速度状态）
返回 true / false
```

## 五、localization_node 内部处理

```
/localization/calibrate_pose 服务回调
        |
        v
设置 is_collecting_ = true
开始在 reflectorPositionCallback 中累积 position_samples_

        ...机器人行走中...

/localization/apply_calibration 服务回调
        |
        v
设置 is_collecting_ = false（停止累积）
        |
        v
跳过前 1/3 样本（去除 LQR 收敛段污染）
  skip = position_samples_.size() / 3
  erase(begin, begin+skip)
        |
        v
fitLine()：最小二乘拟合直线（k, b 或 vertical）
        |
        v
initPose(start, end)：
  计算直线方向角 -> robot_initial_yaw_
  更新 imu_initial_yaw_（当前 IMU 读数）
  initialized_ = true
        |
        v
清空 position_samples_
返回 success=true

/localization/abort_calibration 服务回调
        |
        v
is_collecting_ = false
清空 position_samples_
返回 success=true
```

## 六、并发处理：校准期间收到路径跟随任务

```
execute_plan Action 收到新目标
        |
        v
handleAccepted() -> 在新线程中执行 execute()
        |
        v
execute() 开头（state_mutex_ 保护原子检查）：
  is_executing_ 已为 true？-> 直接 abort 返回
  否则设置 is_executing_ = true
        |
        v
检查 is_calibrating_ 是否为 true
        |
   +----+----+
   |         |
false      true（校准正在进行）
   |         |
   v         v
直接执行    等待 calibration_done_cv_
任务        （calibration_done_mutex_）
            超时 / 取消 / shutdown -> abort
            校准失败 -> abort
                |
                v
            校准完成，继续执行任务
```

---

## 七、校准完成后的状态清理

```
detached 线程（handleCalibrationService 中）完成校准后：
        |
        v
设置 external_calibration_succeeded_ = 校准结果
        |
        v
设置 is_calibrating_ = false
        |
        v
calibration_done_cv_.notify_all()
（唤醒所有等待中的 execute() 任务线程）
        |
        v
等待中的任务线程检查 external_calibration_succeeded_：
  true  -> 继续执行路径跟随
  false -> abort，返回 error_message = "校准失败"
```

---

## 八、异常退出路径

| 情形 | 处理 |
|------|------|
| 节点析构（shutdown_=true） | 所有循环检查 shutdown_ 立即退出；析构函数 notify_all 唤醒等待线程 |
| Action 被取消 | handleCancel 调用 calibration_done_cv_.notify_all()；execute() 检查取消后 abort |
| 质量门控全部重试失败 | abort_calibration -> line_follow_controller_->cancel() -> 返回 false |
| 位姿等待超时（5s） | 本次 retry 失败，sleep 后进入下一次重试（或达上限失败） |
| apply_calibration 服务不可用 | 返回 false，日志报错 |
