# LQR 横向误差（e_y）滤波设计文档

## 背景

`LineFollowController` 使用 LQR 控制角速度，控制律为：

```
ω = ω_ff + ω_fb + ω_i
ω_ff = v × κ          （直线路径 κ=0，恒为 0）
ω_fb = -K1·e_y - K2·e_theta
ω_i  = -Ki · ∫e_y dt  （可选积分项）
```

其中 `e_y` 为 Frenet 坐标系下的横向误差，是影响跟随精度的核心信号。

---

## 一、当前位置滤波流水线

```
pose（原始位姿，传感器精度 ±3mm）
    ↓
Hampel 滤波（window=5, k=3.0, 策略=LINEAR_PREDICTION）
    ↓  去除孤立野点；连续异常 >3 帧后降级为中位数替换
Savitzky-Golay 滤波（window=7, order=3）
    ↓  多项式平滑；噪声衰减系数 ~0.4
control_x / control_y（残余噪声 RMS ≈ 1.2mm）
    ↓
computeLQRErrors → e_y（当前：无额外滤波，直接进入控制律）
```

`e_y` 未经任何独立滤波，继承了上游位置滤波的全部残余噪声。

---

## 二、积分项分析与结论

### 2.1 积分项的作用

`ω_i = -Ki · ∫e_y dt` 是 LQI（Linear Quadratic Integrator）扩展，作用是消除**持续性、单向、低频**横向偏差（如重力侧向分量、系统性传动偏差）。

积分器的工作前提：
- 扰动方向单一（不换向）
- 扰动频率低（缓变）
- `e_y` 长期保持同一符号

### 2.2 不平地面的扰动特征

| 特征 | 积分项假设 | 不平地面实际情况 |
|------|-----------|----------------|
| 扰动方向 | 持续单向 | 随机正负交替 |
| 扰动频率 | 低频缓变 | 高频脉冲 |
| 信号均值 | 非零偏置 | 接近零均值 |

不平地面的扰动违反积分项的全部前提假设。开启积分只会将随机双向噪声累积为缓慢漂移的虚假偏置，反而破坏跟随精度。

### 2.3 结论

> **不平地面场景下，关闭积分项（`enable_integral: false`）是正确选择。**
>
> 积分项适用于坡地、系统性轮子偏差等产生持续单向偏置的场景。

## 三、位置突变导致精度持续恶化的机制

### 3.1 问题现象

实测数据（见附图）显示：一旦发生位置突变，**从突变位置开始，后续整段路径的跟随精度持续下降**，而非仅在突变帧有短暂偏差。

### 3.2 突变残余的产生

位置突变触发 Hampel 连续异常检测，当连续异常帧数超过 `max_consecutive_outliers_`（默认 3）时，Hampel 强制切换为中位数替换：

```
帧 0: 位置突变 +10mm → LINEAR_PREDICTION 输出 +1.5mm
帧 1: 位置仍偏高      → LINEAR_PREDICTION 输出 +2.8mm（置信度衰减）
帧 2: 位置仍偏高      → 达到连续上限，强制切换 REPLACE_MEDIAN
                         此时窗口中位数已被偏高值污染 → 输出 ≈ +5mm
                         单帧跳变 ≈ 2~3mm（阶跃）
```

此阶跃进入 SG 滤波器（window=7），首帧输出约：

```
3mm × SG_h[0] ≈ 1.5mm（仍超出正常噪声帧间变化上限）
```

### 3.3 阶跃对控制系统的连锁伤害

```
e_y 阶跃（1.5mm/帧）
    ↓
omega_raw = -K1 × e_y = -20 × 0.0015 = -0.03 rad/s
    ↓
lqr_angular_smoother 积累状态至饱和
    ↓
applyAngularLimits：clamp(±0.008 rad/s) 触发限幅
    ↓
lqr_angular_smoother.reset()（状态归零）
    ↓
下帧 omega 从 0 重建 → 输出不连续
    ↓
再次触发限幅 → 再次 reset()
    ↓
循环持续约 7 帧（SG 窗口 = 350ms）
```

**精度持续恶化的本质**：不是单帧物理偏转（`max_angular_vel=0.008 rad/s` 限制了单帧物理影响），而是二阶平滑器在 350ms 内反复 reset，角速度输出持续不连续，机器人走出锯齿轨迹。

## 四、e_y 速率限制设计

### 4.1 设计原理

`e_y` 的变化速率受机器人运动学约束：

```
de_y/dt = v × sin(e_theta) ≈ v × e_theta

跟随阶段 e_theta < 0.05 rad，v = 0.2 m/s：
(de_y/dt)_max_physical ≈ 0.2 × 0.05 = 10 mm/s
每帧（50ms）合法变化量 ≈ 0.5mm
```

超出此范围的帧间 `e_y` 变化在运动学上不可能由真实运动产生，必然来自测量噪声或 Hampel 回退阶跃。

### 4.2 阈值设定（3mm 传感器精度下）

传感器精度 ±3mm，经 Hampel + SG 后：

```
残余噪声 RMS ≈ 3mm × 0.4 = 1.2mm
帧间噪声变化（SG 时间相关后）≈ 0.8~1.2mm/帧
```

Hampel 回退阶跃进入 SG 后首帧输出：`≈ 1.5~3mm`

两类信号在阈值两侧具有可分离性：

```
常规噪声帧间变化：0.8~1.2mm  < 阈值 2mm  → 全部通过（限制器静默）
Hampel 回退阶跃：1.5~3.0mm  ≥ 阈值 2mm  → 限制器激活
```

> **阈值推荐：`2.0~2.5mm`（固定值）或 `max(2.0mm, v × dt × factor)`**

### 4.3 实现

```cpp
// 在 computeAngularVelocityLQR 中，computeLQRErrors 之后立即执行

const double max_ey_change = std::max(noise_floor_,
                                      std::abs(linear_speed) * dt * ey_rate_factor_);
const double ey_delta = e_y - prev_ey_;

if (std::abs(ey_delta) > max_ey_change) {
    e_y = prev_ey_ + std::copysign(max_ey_change, ey_delta);
}
prev_ey_ = e_y;
```

参数说明：
- `noise_floor_`：SG 后残余噪声顶部，推荐 `0.002m`（2mm）
- `ey_rate_factor_`：运动学分量系数，推荐 `0.5`

### 4.4 速率限制的核心价值：step → ramp

速率限制不消除扰动的幅度，而是将**阶跃输入转为斜坡输入**：

```
无限制：e_y 在 1 帧内跳变 2mm → omega 饱和 → smoother.reset() 触发

有限制（阈值 2mm）：
    Δe_y = 2mm → 恰好通过，平滑器缓慢累积
    Δe_y > 2mm → 限制为 2mm/帧，转为斜坡
               → omega_raw 缓慢变化，不触发饱和
               → smoother 状态完整，reset() 不触发
               → 角速度输出全程连续
```

### 4.5 正常跟随时零延迟

```
正常跟随：Δe_y/帧 ≈ 0.5mm << 阈值 2mm → 限制器完全静默
突变发生：Δe_y/帧 ≥ 2mm            → 限制器激活

→ 正常工况零延迟、零精度损失
→ 异常工况精准介入
```

这是一阶低通无法做到的特性：**低通永远有延迟，速率限制在正常工况下零延迟。**

## 五、组合策略：速率限制 + 一阶低通

速率限制与低通分工互补，覆盖 `e_y` 噪声的全频段：

| 策略 | 针对扰动类型 | 特性 |
|------|------------|------|
| 速率限制 | 突变残余（离散、阶跃型，>2mm/帧） | 正常工况零延迟 |
| 一阶低通 | 常规噪声（连续、高频型，<2mm/帧） | 均匀衰减 |

### 5.1 低通参数

经速率限制后，残余噪声幅度已被压制，低通可用较高 `alpha` 以减少延迟：

```
alpha 推荐：0.85~0.90
```

### 5.2 完整 e_y 处理流程

```
e_y（来自 computeLQRErrors，继承 1.2mm RMS 残余噪声）
    ↓
[速率限制，阈值 2mm]
    常规噪声 (0.8~1.2mm/帧) → 透明通过，限制器静默
    Hampel 回退阶跃 (>2mm/帧) → 斜坡化，smoother 状态完整
    ↓
[一阶低通，alpha=0.87]
    衰减通过速率限制的常规噪声残余
    ↓
e_y_filtered → omega_fb = -K1 · e_y_filtered
    ↓
lqr_angular_smoother（永不饱和，reset() 不触发）
    ↓
applyAngularLimits（基本不触发限幅）
    ↓
连续、平滑的角速度输出
```

## 六、传感器精度约束下的能力边界

传感器精度 ±3mm，滤波后残余噪声 ≈ ±1mm，这是该方案的根本限制：

```
速率限制 + 低通 能做到：
    ✓ 防止平滑器状态被突变事件破坏
    ✓ 减少角速度输出的不连续性
    ✓ 提高跟随轨迹的平滑度

无法做到：
    ✗ 让跟随精度突破传感器噪声底噪（~1mm RMS after filtering）
    ✗ 区分"真实 1mm 偏差"与"传感器 1mm 噪声"
```

**可达精度估算：**

```
传感器原始：±3mm
Hampel + SG：×0.4 → ±1.2mm RMS
速率限制 + 低通(α=0.87)：×0.36 → ±0.43mm RMS（统计意义）

理论可达跟随精度：2~4mm（95th percentile）
```

`<3mm` 目标处于当前传感器条件的极限边缘，可在平坦地面下达到，不平地面下以统计均值衡量更为合理。
