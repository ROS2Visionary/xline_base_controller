### 根本原因分析（C00）

3. 喷前精度（p90=2.4~6.2mm）远好于喷后（7.0~28.7mm），明确指向 limit_ratio_after_print 是关键

## C01 — 喷后反馈限制 5%→20%

| 字段 | 值 |
|------|---|
| **batch_id** | 待测 |
| **日期** | 2026-03-07 |
| **父批次** | circle_C00_baseline |
| **唯一变更** | `limit_ratio_after_print: 0.05 → 0.20` |
| **理由** | C00 喷后饱和率99%+，4倍提升修正能力，使其与喷前一致 |
| **结果** | 待测 |

### 配置快照（C01）
```yaml
feedback:
  limit_ratio_before_print: 0.20   # 不变
  limit_ratio_after_print: 0.20    # 0.05 → 0.20（唯一变更）
  min_limit: 0.0
```

### 预期
- 饱和率从99%+下降（若p90降至~5mm区间，K1×0.005=1.0 rad/s，仍远超20%×ω_ff≈20mrad/s，依然饱和但修正量4倍）
- 喷后p90从7~28mm → 预计降低至3~10mm区间
- Q2偏差不变（环境问题）

### 若C01效果不足的后续方向
- C02: `use_direct_gains: true`，设置更小的K1/K2（20~50），使LQR不饱和，真正进入比例控制区
- 或: 进一步提高 limit_ratio_after_print（0.20→0.40），但需评估抖动风险
