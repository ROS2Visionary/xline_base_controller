### 根本原因（C03数据确认）
- bang-bang饱和率93-95%，omega落在ff±5%内仅1-8%
- 根因：`std::clamp` + K1=202-283 → raw=0.4-1.4rad/s >> limit=5-50mrad/s → 纯继电控制
- 解法需同时从**代码结构**和**增益幅度**两端解决

### 变更内容（C04 vs C03）
| 层级 | 参数/代码 | C03 | C04 | 原理 |
|------|----------|-----|-----|------|
| **代码** | 限幅方式 | `std::clamp` | **`std::tanh`软饱和** | clamp=继电器；tanh=平滑比例区 |
| **YAML** | use_direct_gains | false | **true** | 切换到直接增益模式 |
| **YAML** | K1_direct | (LQR=282) | **3.0** | K1×5mm=15mrad≈5%×ω_ff_min，不超限 |
| **YAML** | K2_direct | (LQR=28.1) | **1.0** | 航向项不主导 |
| **YAML** | enable_integral | false | **true** | K1小→必须积分消稳态误差 |
| **YAML** | Ki | 0.5 | **8.0** | 积分时间常数~1.5s，覆盖~6%圆弧 |
| **YAML** | integral_max | 0.1 | **0.025** | 覆盖~20-25mrad/s地面扰动 |
| **YAML** | limit_ratio_before | 0.30 | **0.05** | tanh下5%=连续比例区，不是bang-bang |
| **YAML** | limit_ratio_after | 0.30 | **0.05** | 同上 |
| **YAML** | velocity_step | 0.01 | **0.02** | 大半径加速（已实施）|

### ±5%可行性验证（理论）
```
ω_ff_min = v_min/R_max_test = 0.05/0.705 = 70.9 mrad/s
limit = 0.05 × 70.9 = 3.55 mrad/s

e_y=2mm → raw=K1×2mm=6mrad/s → tanh(6/3.55)×3.55 = 3.37mrad/s = 4.8%ω_ff ✓
e_y=5mm → raw=15mrad/s → tanh(15/3.55)×3.55 = 3.54mrad/s = 5.0%ω_ff ✓（上边界）
积分稳态 → integral_max=25mrad/s（比例区内展现为缓慢收敛，不影响omega连续性）
```

## C05 — 双路反馈架构 + 跳变检测

| 字段 | 值 |
|------|---|

| **日期** | 2026-03-08 |

| **变更说明** | 代码架构升级（多项耦合变更，不可再分）|
| **结果** | 待测 |

### 架构变更（C05 vs C04）

**控制律结构变化：**
```
C04（失败）：omega_correction = tanh((omega_fb + omega_i) / limit) × limit
                                 ↑ 积分被 tanh 吞噬，无额外修正能力

C05（新）：omega_prop = tanh(omega_fb / prop_limit) × prop_limit   ← 比例路径（平滑）
           omega_int  = clamp(omega_i, ±int_limit)                 ← 积分路径（修正力）
           omega_correction = omega_prop + omega_int                ← 两路独立叠加
```

**参数对比（C05 vs C04）：**
| 参数 | C04 | C05 | 原因 |
|------|-----|-----|------|
| K1_direct | 3.0 | **6.0** | 比例路径独立后可提高K1（不再担心积分被吞噬）|
| K2_direct | 1.0 | **1.5** | 适中航向阻尼 |
| limit_ratio_before | 0.05 | **0.12** | 喷前快速收敛，评判≈ff±8-10% |
| limit_ratio_after | 0.05 | **0.08** | 喷后精度，评判≈ff±5-6% |
| int_limit_ratio | — (新) | **0.20** | 积分独立路径，修正系统性±4-8mm偏差 |
| max_ey_jump_m | 0.0 | **0.008** | 8mm/cycle跳变保护 |
| Ki | 8.0 | 8.0 | 不变 |
| integral_max | 0.025 | 0.025 | 不变 |

### 预期 omega 行为
| 指标 | C04(实测) | C05(预期) |
|------|-----------|----------|
| 比例项贡献(e_y=2mm) | ≈5mrad/s(上限) | tanh(12/8)×8=7.4mrad/s=7.4%ff |
| 积分项贡献(稳态) | ≈0（被淹没）| ±20%ff（修正+4-8mm偏差）|
| omega落在ff±5%内 | 61-99%（虚假，因修正≈0）| 约80%（喷后稳态，e_y<1mm时）|
| 精度 p90_radial | 9.7-19.8mm | 目标3-6mm |

### 新增机制说明
1. **双路解耦**：比例路径负责瞬时平滑（ω≈ff±5-8%），积分路径负责稳态修正（可到±20%），互不干扰
2. **跳变检测**：max_ey_jump_m=8mm，防止定位抖动时积分学习虚假偏差
3. **前馈充分利用**：ω_ff=v/R 是圆弧跟踪核心，两路反馈均以前馈为基准比例计算
